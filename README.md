# 📊 HR Attrition Analysis Dashboard (Power BI & Microsoft Fabric)

End-to-end BI solution analyzing employee turnover across 1,470 records to uncover retention drivers and high-risk segments.

## 🛠️ Tech Stack
* **ETL & Storage:** Microsoft Fabric (Dataflows Gen2, Lakehouse)
* **Modeling & Logic:** Star Schema, DAX
* **Visualization:** Power BI Desktop (Decomposition Tree, Bookmarks, Conditional Formatting)

## 🔍 Key Insights
* **Baseline:** **16.1% attrition** (237 of 1,470 employees), $6.50K avg monthly income, 5.1 yrs avg tenure[cite: 1].
* **Top Drivers:** Overtime workers (**30.5%** vs. 10.4%), Age 18–25 (**35.8%**), Salary <$3K (**28.6%**), Frequent Travel (**24.9%**), and Sales Reps (**39.8%**)[cite: 1, 2].
